# Школьные конкурсы — прототип платформы

Веб-платформа для школы: анонсы конкурсов, запись учеников, учёт результатов, выдача дипломов (PDF с QR-кодом), отчёты.

Основной сценарий: **регистрация → запись на конкурс → внесение результатов → выдача диплома → скачивание**.

## Состав

| Компонент | Технология |
|---|---|
| Backend | Python 3.12, FastAPI, SQLAlchemy 2, argon2, JWT в httpOnly-cookie + CSRF |
| БД | PostgreSQL 16 (схема в `backend/migrations/001_init.sql`, применяется автоматически) |
| PDF / Excel | WeasyPrint, qrcode, openpyxl |
| Frontend | React 18, TypeScript, Vite, Tailwind, React Query |
| Почта | Mailpit (локальный перехватчик, письма наружу не уходят) |
| Запуск | Docker Compose |

## Запуск

Нужны Docker и Docker Compose.

```bash
cp .env.example .env        # при желании отредактируйте пароли и SECRET_KEY
docker compose up --build
```

Первая сборка занимает несколько минут. Когда в логах появится `Application startup complete`, откройте:

| Адрес | Что это |
|---|---|
| http://localhost:8080 | Платформа |
| http://localhost:8025 | Mailpit: все «отправленные» письма (подтверждение email, сброс пароля) |
| http://localhost:8080/api/docs | Swagger — интерактивная документация API |

Остановка: `Ctrl+C`, затем `docker compose down`. Удалить все данные: `docker compose down -v`.

|---|---|---|
| Администратор | `admin@school.local` | `Admin12345` |
| Ученик (победитель олимпиады) | `ivan@school.local` | `Student123` |
| Ученик (призёр) | `maria@school.local` | `Student123` |
| Остальные ученики | `alexey@`, `darya@`, `maxim@`, `anastasia@`, `egor@`, `polina@`, `artem@`, `sofia@`, `anna@`, `petr.a@`, `petr.b@school.local` | `Student123` |

В демо уже есть: завершённая олимпиада и командный «Брейн-ринг» с выданными дипломами, идущий конкурс по информатике, предстоящие олимпиада по русскому языку и командный турнир по физике (команда «Ньютоны», код `NEWTON`), черновик.

## Сценарий демонстрации

**Часть 1. Ученик** (вход: `ivan@school.local` / `Student123`)

1. «Мои дипломы»: у Ивана два диплома. Откройте PDF: есть рамка, ФИО, место, номер и QR-код.
2. Отсканируйте QR (или нажмите «Проверка»): страница подлинности показывает ФИО сокращённо, «Иванов И. П.».
3. «Мой прогресс»: статистика, места и баллы.
4. «Конкурсы»: отфильтруйте по предмету «Русский язык», откройте олимпиаду и нажмите «Записаться».
5. Откройте «Турнир по физике»: создайте команду или вступите в «Ньютоны» по коду `NEWTON`.

**Часть 2. Новый ученик** (проверка регистрации)

1. Выйдите, нажмите «Регистрация», заполните форму.
2. Откройте Mailpit (http://localhost:8025), перейдите по ссылке из письма. Затем войдите.

**Часть 3. Администратор** (вход: `admin@school.local` / `Admin12345`)

1. «Мероприятия» → «+ Новое мероприятие»: создайте «Олимпиада по физике», статус «Опубликовано».
2. Вкладка «Участники и импорт»: загрузите `docs/sample-import.csv`. В предпросмотре будут строки всех типов: найденные, неоднозначная («Петров Пётр», выберите 8Б), новый ученик (создастся учётная запись и придёт приглашение в Mailpit), строка с ошибкой (нет класса). Нажмите «Применить импорт».
3. Вкладка «Результаты»: введите место, баллы и статус. Нажмите «Сохранить результаты».
4. Вкладка «Дипломы»: «Сгенерировать дипломы», затем откройте PDF.
5. Войдите учеником, которого вы записали (например, `ivan@school.local`): диплом появился в «Мои дипломы», его можно скачать.
6. «Отчёты»: выгрузите отчёт по классам в XLSX, по ученикам в CSV, за период в PDF.
7. «Пользователи»: назначьте ученика администратором или заблокируйте.
8. «Шаблон диплома»: измените текст или цвета, сохраните. Новые дипломы получат новый вид.

## Формат файла для импорта

CSV (UTF-8 или Windows-1251, разделитель `;` или `,`) или XLSX. Первая строка: заголовки.

| Колонка | Обязательна | Пример |
|---|---|---|
| `ФИО` (или `Фамилия` и `Имя`, `Отчество`) | да | Иванов Иван Петрович |
| `Класс` | да | 8Б |
| `Email` | нет | ivan@example.com |
| `Команда` | для командных | Эрудиты |

Ученик ищется по email, затем по ФИО и классу. Если не найден, а email указан, создаётся учётная запись и отправляется приглашение для установки пароля. При нескольких совпадениях (однофамильцы) администратор выбирает нужного вручную.

## Настройки (`.env`)

| Переменная | Назначение |
|---|---|
| `SECRET_KEY` | Ключ подписи JWT. **Обязательно смените** |
| `PUBLIC_BASE_URL` | Адрес платформы: используется в QR-кодах и письмах |
| `REQUIRE_CONSENT` | `true` — при регистрации обязательный чекбокс согласия на обработку ПДн |
| `SEED_ON_START` | `false` — не создавать демо-данные |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | Первый администратор |
| `COOKIE_SECURE` | `true` при работе по HTTPS |

QR-коды ведут на `PUBLIC_BASE_URL`: если платформа открывается по другому адресу (например, `http://192.168.1.10:8080`), укажите его до выдачи дипломов.

## Безопасность (что реализовано)

- Пароли: argon2. Блокировка на 15 минут после 5 неверных попыток входа.
- Сессия: JWT в `HttpOnly` cookie, защита от CSRF (double-submit токен в заголовке `X-CSRF-Token`).
- Роли проверяются на сервере для каждого админского эндпоинта.
- ORM с параметрами запросов (SQL-инъекции), экранирование в React и Jinja2 (XSS), шаблон диплома рендерится в «песочнице».
- Загрузка файлов: белый список типов, проверка сигнатуры, лимит размера, имена файлов заменяются на UUID.
- Токены писем хранятся в виде хеша, одноразовые, со сроком жизни.
- Номера дипломов случайные, публичная проверка показывает только сокращённое ФИО.
- Backend в контейнере работает не от root.

## Разработка без Docker

```bash
# backend (нужен PostgreSQL и системные библиотеки WeasyPrint)
cd backend && pip install -r requirements.txt
DATABASE_URL=postgresql+psycopg://user:pass@localhost/contests DATA_DIR=./data SMTP_HOST=localhost SMTP_PORT=1025 \
  uvicorn app.main:app --reload

# frontend (проксирует /api на localhost:8000)
cd frontend && npm install && npm run dev      # http://localhost:5173
```
