# План развития: от прототипа к продакшену

## Этап 0. Прежде чем показывать ученикам (1–2 недели)

- **Первый запуск и проверка.** Прототип собран, но целиком не запускался в среде разработки. Пройти сценарий из README, исправить найденное.
- **Автотесты.** pytest для API (регистрация, запись, результаты, диплом, права доступа, импорт), несколько e2e на Playwright.
- **Юридическая часть (152-ФЗ).** Согласие на обработку: для учеников младше 14 лет его даёт родитель. Включить `REQUIRE_CONSENT`, добавить текст согласия и политику обработки данных. Назначить ответственного за обработку ПДн, уведомить Роскомнадзор, если требуется. Серверы в РФ.
- **HTTPS и домен.** Reverse-proxy (Caddy или nginx) с сертификатом, `COOKIE_SECURE=true`, актуальный `PUBLIC_BASE_URL`, чтобы QR в дипломах вёл на постоянный адрес.
- **Секреты.** Уникальные `SECRET_KEY`, пароли БД и администратора; `SEED_ON_START=false`.

## Этап 1. MVP для одной школы (1–2 месяца)

- Реальная почта: SMTP школы вместо Mailpit, SPF/DKIM.
- Резервные копии: ежедневный `pg_dump` и копия тома с дипломами, проверка восстановления.
- Миграции через Alembic вместо простого накатчика SQL-файлов.
- Лимит попыток и частоты запросов на уровне прокси (по IP), журнал входов.
- Фоновая очередь для массовой генерации дипломов и писем (сейчас всё в запросе).
- Редактор шаблонов с предпросмотром и загрузкой логотипа, подписи и печати; несколько шаблонов по уровню конкурса.
- Лимиты мест и дедлайн записи, одобрение записи администратором (по желанию).
- Уведомления ученикам: напоминание о конкурсе, «диплом готов».
- Роль «учитель» с доступом только к своим предметам или классам.
- Журнал действий (`audit_log` уже заполняется): страница просмотра.

## Этап 2. Продакшн (3–6 месяцев)

- Интеграция со школьной системой (электронный журнал, ГИС «Моя школа» или аналог): список учеников и классов, автоматический переход на следующий учебный год (класс +1).
- Вход через Госуслуги или школьный SSO, двухфакторная защита для администраторов.
- Портфолио ученика: накопленные достижения, выгрузка для поступления.
- Публичная страница школы с рейтингом и новостями; календарь мероприятий (iCal).
- Мониторинг (Prometheus + Grafana), централизованные логи, оповещения об ошибках.
- Горизонтальное масштабирование: хранение файлов в S3-совместимом хранилище, несколько экземпляров backend.
- Аудит безопасности и нагрузочное тестирование; процесс обновления и отката.
- Доступность: проверка по WCAG, версия для слабовидящих.

## Известные ограничения прототипа

| Область | Сейчас | Что делать |
|---|---|---|
| Тесты | Нет | pytest + Playwright |
| Миграции | Простой накатчик SQL | Alembic |
| Файлы | Локальный том Docker | S3-хранилище |
| Генерация дипломов | Синхронно в запросе | Очередь задач |
| Браузер | Проверка только в разработке | Проверка на мобильных и в разных браузерах |
| Шаблон диплома | Один, правка HTML | Конструктор, несколько шаблонов |
| Пароль администратора | Из `.env` | Принудительная смена при первом входе |
